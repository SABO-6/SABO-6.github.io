SABO: Safe and Aggressive Bayesian Optimization for Automatic Legged Locomotion Controller Tuning

Haobo Zhang*,   Zhiyong Yu*,   Hengquan Guo,   Yuning Jiang,   Yizheng Zhang,   Xin Liu,   Yuanming Shi
Submitted to IROS 2025
Paper Video Code Summary

Abstract

This project addresses the challenge of optimizing controller parameters in complex robotic systems under safety constraints. We propose Safe and Aggressive Bayesian Optimization (SABO) algorithm, which leverages Gaussian processes (GPs) to model both reward and constraint functions while using an adaptive penalty to balance the tradeoff of reward and cost. Compared to the state-of-the-art algorithm, GOSAFEOPT, which relies on prior system knowledge—such as an initial safe set and the Lipschitz constant of cost functions—to construct a safe and conservative decision set, SABO synthesizes a single surrogate function by adaptively penalizing the cost functions, and encourages safe but aggressive exploration. We implement SABO in both simulations and hardware experiments on a quadruped robot. The results show that it outperforms GOSAFEOPT, offering a safer, more sample-efficient, and robust solution for bridging the sim-to-real gap in dynamic environments.
